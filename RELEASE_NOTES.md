## Memento 900 v0.2.0

**New in this release:**

- 🌅 **Daily quote** — a memento-mori thought in the header, rotating once per
  day (bilingual EN/中文). The same day always shows the same quote.
- 🕰️ **"Look back" timeline** — a chronological feed of every month you've
  recorded. Scroll through your life fragments; tap any entry to jump to that
  month.

Plus all the v0.1.0 essentials: the 900-month grid, per-month moments
(notes, mood, tags, photos), 100% local SQLite storage, and EN/中文 switching.

### Install (Windows 64-bit)
1. Download `Memento 900_0.2.0_x64-setup.exe` below
2. Run it (installs for the current user — no admin needed)
3. Launch from the Start menu

Your data is saved at `%APPDATA%\com.memento900.app\memento900.db` and is
**preserved across updates** — installing this version keeps your existing
records.

> Windows SmartScreen may warn the publisher is unknown (the app isn't
> code-signed). Click **More info → Run anyway**.
