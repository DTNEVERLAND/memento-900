## Memento 900 v0.1.0 — first release

**900 months, one grid.** A privacy-first, local-first life tracker.

### What's inside
- 🗓️ The 30×30 grid of 900 months, computed precisely from your date of birth
- 📝 Record any month — notes, mood, tags, and photos per moment
- 🔒 100% local: data lives in a SQLite file on your device. No account, no cloud, no tracking
- 🌐 English / 简体中文
- 🪶 ~1.7 MB installer, built with Tauri 2

### Install (Windows 64-bit)
1. Download `Memento 900_0.1.0_x64-setup.exe` below
2. Run it (installs for the current user — no admin needed)
3. Launch from the Start menu

Your data is saved at `%APPDATA%\com.memento900.app\memento900.db`.
To move machines, copy that file.

> Windows SmartScreen may warn that the publisher is unknown (the app isn't
> code-signed). Click **More info → Run anyway**. The source is fully open here.
